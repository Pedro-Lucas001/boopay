# RB-001 — Aceite do sprint WooCommerce

Autor: Thiago Ventura. Estado: proposta verificável, revisão pendente.
Issue: [#1](https://github.com/Pedro-Lucas001/boopay/issues/1).

## Escopo da entrega

Plugin nativo instalável por ZIP, conexão com API e credenciais revogáveis,
catálogo inicial paginado (simples/variável/vazio), atualização/exclusão,
fila com retries limitados, saúde e eventos de vitrine com consentimento.
Checkout, pagamento, Google Pay, ACP/UCP, Shopify e VTEX são marcos posteriores;
não fazem parte da demonstração deste sprint.

## Ambiente e compatibilidade

| Componente | Base proposta | Evidência atual |
| --- | --- | --- |
| API | Node 22 na CI; Node 24.18.0 local | Compilação e testes backend locais; CI pendente |
| PHP | 8.3 como alvo inicial | Cliente isolado a validar em RB-013; plugin instalado pendente |
| Prisma | 5.22.0, SQLite da implementação atual | Testes de migração em banco temporário em RB-011 |
| WordPress | Versão estável da loja de teste, fixada antes do aceite | Ainda não informada/instalada |
| WooCommerce | Versão da loja de teste, fixada antes do aceite | Ainda não informada/instalada |
| HPOS | Ligado e desligado se o plugin acessar pedidos | Ainda sem execução |

Nenhuma versão WordPress/WooCommerce é declarada suportada sem execução
da matriz. Antes da liberação, registrar as versões exatas, o ZIP e seu hash
e repetir os cenários abaixo. Um cliente PHP isolado não constitui plugin
ativável. O banco SQLite atual não comprova a futura migração PostgreSQL.

## Porta de aceite e demonstração

1. Fixar versões e dados sintéticos, cadastrar loja e gerar ZIP.
2. Executar P01–P17 registrando esperado/observado, versão, hash e evidência.
3. Falha de autorização, vazamento ou perda/duplicação indevida bloqueia aceite.
4. Gravar conexão → catálogo → alteração/exclusão → evento consentido → falha
   controlada → recuperação. Mostrar os dados recebidos na API.
5. Pedir revisão independente, corrigir e repetir cenários afetados.
6. Manter pendências explícitas; não declarar a loja validada com base em mocks.
