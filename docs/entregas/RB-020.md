## Reprodução

```bash
npm ci --ignore-scripts
npm run db:generate
npm run qa:evidence
npm run qa:plugin
```

PHP 8.3 precisa estar no PATH ou em PHP_BINARY. qa:evidence usa somente
dados sintéticos e bancos temporários. qa:plugin sem ZIP/ambiente retorna
2 (bloqueado), deliberadamente. Não transformar esse resultado em sucesso.

Quando os artefatos existirem, fornecer:

```bash
npm run qa:plugin -- --plugin-zip CAMINHO_DO_ZIP --environment AMBIENTE_JSON
```

AMBIENTE_JSON contém somente wordpress, woocommerce, php, database e hpos.
Preflight registra disponibilidade, versões informadas e SHA-256; **não
comprova** instalação, conteúdo do ZIP nem aprovação dos cenários.

## Matriz a executar na loja limpa

| Cenário | Esperado | Resultado real nesta entrega |
| --- | --- | --- |
| ZIP novo e ativação | Sem fatal, dependências reconhecidas | Não executado: plugin/ZIP ainda ausentes |
| Conectar/desconectar pela tela | Código limpo e credencial revogada | Backend testado; tela e jobs pendentes |
| Catálogo simples/variável/vazio | Dados corretos e carga paginada retomável | Não executado na loja |
| Atualizar/excluir/última variação | Projeção consistente sem ressurreição | Proteção de SKU testada; integração pendente |
| Repetição/concorrência | Sem duplicar eventos ou estado | Nonce e código testados; ingestão RB-016 pendente |
| Timeout/retry/permanente | Timeout definido; retry limitado | Opções PHP testadas; rede/fila pendentes |
| Consentimento/eventos | Sem envio desligado; payload mínimo | Não executado: RB-018/RB-019 pendentes |
| Logs sem segredos | Tokens/códigos/assinaturas ausentes | Teste automatizado de logs passou |
| HPOS ligado/desligado | Compatible se houver acesso a pedidos | Não executado; não declarar N/A sem inspecionar plugin final |
